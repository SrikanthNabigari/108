# 108 - Personal Life Operating System

> "Decode how astrology is our complete operating system"

A Personal Life Operating System powered by Vedic Astrology (Jyotish).

## Features

- Calculate all Vedic Jyotish elements with precision
- Predict past, present, and future
- Adapt to each person through detected personality
- Guide with tasks and scheduled events
- Learn from every conversation

## Quick Start

```bash
# Install dependencies
uv sync

# Run API server
uv run uvicorn services.api.main:app --reload

# Run tests
uv run pytest
```
